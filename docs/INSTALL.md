# 安装、卸载与回滚

当前仅发布源码，没有可下载的正式安装包。自行构建的候选与任何未来的签名、公证发行包应明确区分。

## 安装或更新

1. 按 README 构建并完成严格离线检查，核对候选来源、版本、架构与哈希。尚未正式签名、公证的候选不能冒充完成公证的发行包；遇到系统安全提示时停止并核实来源，不提供关闭安全检查的步骤。
2. 更新前保留原 `.app` 的完整副本，记录二进制哈希及原运行位置。不要覆盖唯一回滚包。
3. 从应用菜单正常退出旧版。若提示重新开启未确认，先在系统 Wi-Fi 菜单处理；不要强制结束正在承担开启清理责任的进程。
4. 确认旧进程已退出后，将已核验的候选复制到所选应用目录，例如当前用户的 `~/Applications/`。替换期间会有监测中断。
5. 正常打开新应用，核对实际启动时间、进程、包路径、版本与哈希。每次新进程自动恢复默认关闭；需要本人在应用内确认风险后再开启。
6. 若有独立采集器，结束旧版本的证据窗口，记录切换缺口，并用新进程与新哈希建立基线。旧版观察时间不能并入新版验收。

## 回滚

先正常退出当前版本，再恢复保留的旧 `.app` 并启动。核对旧包哈希及实际运行进程。不要手动编辑恢复事务、重试或冷却文件来实现回滚；不兼容或未知状态应按应用保守提示处理。回滚产生新的观察窗口，且自动恢复仍须本次应用确认。

## 卸载与本地数据

正常退出并确认没有未完成的无线电开启责任后，可将应用移到废纸篓。停止独立采集器只影响采集器，不代替应用的安全退出。

如需保留设置和诊断，保存 `~/Library/Application Support/WiFiSentinel/` 的私密备份。完全移除数据会删除设置、日志以及重试／冷却记录；不要在应用运行或存在未完成事务时删除它们。卸载后重新安装不能视为原观察窗口的延续。

定位和辅助功能等系统权限由 macOS 管理；卸载文档不要求修改隐私数据库或网络权限。本机验证辅助程序不应成为普通用户安装包的依赖。
