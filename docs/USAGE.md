# 指定已保存网络重联

这是一个可选的进阶功能。普通使用可以先留空已保存网络名称，让 macOS 自己重新加入网络。

通常先让 macOS 自己重新加入网络即可。如果要使用应用的已保存网络重联路径，可以在检测参数页选择“授权并读取当前 Wi-Fi 名称…”，按系统提示由自己决定是否允许定位，然后保存目标。

这条路径还需要单独确认“单次验证已保存网络重联…”，并且只在自然未关联、现有权限足够时尝试。它不会为了验证主动断开 Wi-Fi，也不读取密码；未通过本次运行的验证时，不会拿这个目标自动重联。这个功能仍有兼容性限制，不保证能重新加入所有网络。

定位授权由你在系统弹窗中决定。拒绝或权限不足时应用会停止，不会提权、读取密码或反复申请。具体兼容性限制见[验证说明](VALIDATION.md)。
