# 隐私与诊断数据

本应用的设置、事件、快照与恢复策略状态保存在本机用户目录。配置的网络名称可能以明文出现在设置和运行快照中；网关、接口、地址派生摘要、权限、故障、尝试次数和时间也可能出现在诊断中。哈希仍可能被猜测或关联，不能保证匿名。

业务探测默认向以下公开目标发送有界请求：

- `https://www.apple.com/library/test/success.html`
- `https://www.cloudflare.com/cdn-cgi/trace`

用户可设置其他目标。请求目标、网络中间设备及 VPN 服务可能观察来源地址、时间与连接特征。应用不把本机观察日志上传到维护者服务，也不读取 Wi-Fi 密码、私钥或位置坐标。

发布源码时应使用明确允许的文件清单，排除 `.build/`、`build/`、应用数据、采集记录、系统截图、回滚副本、签名材料和个人配置。不要将本地审计目录整体上传。

提交问题前先检查并删去 SSID、地址、用户名、主机名、私人路径及其他可识别信息。优先使用合成数据复现。不要在公开 Issue 中粘贴完整设置或原始运行快照。
